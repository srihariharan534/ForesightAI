# Contributing to ForesightAI

We welcome contributions! Please follow our established Development Workflow.

## Workflow
1. **Design**: Document architectural changes in `docs/`.
2. **Implement**: Code following our strict Coding Standards.
3. **Validate**: Ensure logic meets business requirements.
4. **Test**: Write and pass unit tests (`make test`).
5. **Document**: Update docstrings and markdown files.
6. **Optimize**: Run profilers to ensure performance targets.

## Commit Guidelines
Use Conventional Commits (e.g., `feat: add new prediction endpoint`, `fix: correct JWT validation`).

## Pull Requests
- Ensure PRs pass all CI/CD pipelines (Lint, Format, Type Check, Tests).
- A PR requires at least one code review approval.
- Code must maintain or improve test coverage.
